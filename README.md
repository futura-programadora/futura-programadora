## Sobre

Sou desenvolvedora autodidata, com 4 anos de experiência construindo software do zero — do banco de dados à interface. Trabalho em desenvolvimento web, aplicativos mobile, automações e sistemas de gestão, sempre com foco em arquitetura organizada e código sustentável.

Não venho de uma formação acadêmica em tecnologia, mas isso nunca foi um limite: aprendi na prática, testando, quebrando e refazendo, até conseguir entregar sistemas reais, em produção, usados por estudantes, empreendedores e empresas. Hoje isso se traduz em um jeito de trabalhar mais prático e resolutivo — prefiro entender o problema de negócio por trás de cada funcionalidade do que só seguir uma especificação.

Atualmente lidero a **VionTech**, minha marca de tecnologia, e desenvolvo o **[VionBuilder](https://vionbuilder.com.br)**, um SaaS com ferramentas voltadas ao empreendedorismo — meu principal produto e também minha prova de trabalho, atualizado constantemente.

<br>

## Como eu trabalho

- **Do banco à tela**: participo do projeto inteiro — modelagem de dados, API, lógica de negócio e interface — não só de uma camada isolada.
- **Arquitetura antes de código**: organizo a estrutura do projeto (MVC, separação de responsabilidades) antes de sair escrevendo, pensando em manutenção futura.
- **Aprendizado contínuo**: como sou autodidata, tenho o hábito constante de estudar novas ferramentas e aplicar o que funciona de verdade, sem modismo.
- **Produto próprio como laboratório**: uso o VionBuilder para testar decisões técnicas antes de recomendar algo a um cliente.

<br>

## VionBuilder — meu produto

SaaS com múltiplas ferramentas para empreendedores, construído com Laravel, PHP, MySQL e PDO.

**[vionbuilder.com.br](https://vionbuilder.com.br)**

Um projeto real, em produção, onde aplico diariamente:

- Arquitetura MVC e organização por módulos
- APIs REST para comunicação entre front-end e back-end
- Automações com n8n para integrações entre sistemas
- Modelagem de banco de dados relacional (MySQL)
- Interfaces responsivas do Desktop ao Mobile
